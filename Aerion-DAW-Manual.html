Chapter 01

Welcome to Aerion

Aerion DAW is a free, open-source digital audio workstation for recording, arranging, editing and mixing music on Windows and macOS. It is developed by Aethos Studio and built on the JUCE framework and Tracktion Engine.

This manual covers version 0.5.1 Alpha. Everything described here works in that version. Where a feature is only partly there, the manual says so, and Known limitations lists what is still missing. You can open this manual at any time from Help › User Manual; it opens in your web browser and works without an internet connection.

!

Aerion is alpha software. Keep backups of projects you care about. The project file format may still change before version 1.0.

How Aerion thinks about a song

  • A project is one song, saved as a single .aerion file. The audio it uses stays where it is on disk, or is copied into the project folder by Collect & Save.
  • A project holds tracks: audio tracks for recordings and samples, MIDI tracks for notes that play an instrument, and folder tracks that group other tracks.
  • Tracks hold clips on the timeline: audio clips (a stretch of a recording) and MIDI clips (a set of notes).
  • Each track runs its sound through a chain of devices (instruments and effects), then its fader, pan and meter, and into the master track.

Chapter 02

Installing

Download the installer for your system from the release page on GitHub: the .exe for Windows, the .dmg for macOS.

Windows

  1. Run the downloaded .exe.
  2. Windows SmartScreen shows “Windows protected your PC”, because the installer isn't code-signed yet. Click More info, then Run anyway.
  3. Follow the installer. It adds Aerion DAW to the Start menu and installs the Visual C++ runtime it needs.

macOS

  1. Open the .dmg and drag Aerion DAW into Applications.
  2. Open Aerion. macOS says it can't check the app for malicious software, because it isn't notarized yet.
  3. Open System Settings › Privacy & Security, scroll down, and click Open Anyway next to the message about Aerion DAW. You only need to do this once.
  4. Allow microphone access when macOS asks. Aerion needs it to record from any audio input, not only a microphone.

The first start

Aerion shows a splash screen while it opens your audio device, then the main window with an empty project.

In the background it scans your computer for plugins: VST3 on Windows and macOS, plus Audio Units on macOS. The Plugins tab of the Browser shows SCANNING until it finishes. Each plugin is checked in a separate process, so a plugin that crashes while being checked is skipped, and Aerion keeps running.

Chapter 04

Audio & MIDI setup

Open File › Audio Settings… (also under the Audio menu) to choose your audio interface, its sample rate and buffer size, and your MIDI inputs.

Choosing an audio device

  1. Pick the Audio device type. On Windows use ASIO if your interface has an ASIO driver. Otherwise use Windows Audio. On macOS it is Core Audio.
  2. Pick the Output and Input device, and tick the input channels you want to record from.
  3. Set the Sample rate (48 000 Hz is a good default) and the Buffer size.
  4. Tick the MIDI inputs (keyboards, controllers) you want Aerion to listen to.

Buffer size and latency

The buffer size is how much audio Aerion works out at a time. Smaller buffers mean less delay between playing and hearing, which matters when you record. Larger buffers give the computer more room and avoid clicks and dropouts, which matters when a mix has many plugins. 128 or 256 samples suit recording; 512 or 1024 suit mixing.

The left end of the transport bar shows the current setup:

  • SR: the sample rate, for example 48.0 kHz.
  • BUF: the buffer size and how long it lasts, for example 256@5.3ms.
  • CPU: how much of each buffer's time Aerion needs. Blue is fine, yellow (above 60 %) is getting busy, and red (above 85 %) risks dropouts.
i

Stuck with a bad setting? If a driver change left you with a wrong sample rate or no sound, click Reset Audio Settings at the bottom of the Audio Settings window. Aerion forgets the saved setup and picks a safe default: ASIO if it is installed, otherwise Windows Audio.

The Audio Settings window also holds the Auto-save interval (see Projects).

Unsaved changes

The window title shows the project's name with asterisks, as in *My Song*, when it has changes that aren't saved. When you quit, open another project or start a new one with unsaved changes, Aerion asks whether to save them. Save saves first, Discard throws the changes away, and Cancel or Esc leaves everything as it was. When quitting, the buttons read Save & Quit and Discard & Quit.

Auto-save and crash recovery

Aerion saves a recovery copy of your project in the background every 5 minutes. Change the interval, or turn it off, in File › Audio Settings… under Auto-save (Off, 1, 2, 5 or 10 minutes). The recovery copy is separate from your project file, which is only written when you save.

If Aerion closes unexpectedly, the next start says so. It first offers to show the crash report (see Troubleshooting), then asks whether to restore the auto-saved session. Restore opens it; Discard starts fresh.

Chapter 06

Tracks

Add tracks with the + Audio, + MIDI and + Folder buttons above the track headers, or from the Track menu.

Audio track
Records and plays audio clips. Its devices are effects.
MIDI track
Records and plays MIDI clips. Add an instrument plugin to hear them.
Folder track
Groups other tracks so you can fold them away. It can also act as a submix bus with its own fader.

The track header

Each track's header, on the left of the timeline, shows its name, colour and these buttons:

  • M Mute silences the track (M).
  • S Solo plays only soloed tracks (S).
  • R Record arm makes the track record when you press Record (R).
  • A Automation shows or hides the track's automation lane.
  • FX opens the window that lists the track's devices.

The keyboard shortcuts act on the selected track.

Selecting and arranging tracks

  • Select a track by clicking its header. Shift-click adds or removes tracks from the selection. The Inspector always shows the track you clicked last.
  • Reorder by dragging a header up or down. A line shows where it will go.
  • Put a track in a folder by dragging it onto the folder's header, or with Move into folder in its right-click menu. Detach from folder takes it out again.
  • Fold a folder with the arrow next to its name.
  • Change a track's height by dragging the bottom edge of its header. Selected tracks resize together. Double-click the edge to reset it, or choose Small, Normal, Large or Huge from Track Height in the right-click menu. Heights are saved with the project.
  • Delete the selected tracks with Delete, Track › Delete Track or the right-click menu.

Chapter 08

Editing clips

Most editing happens with the Select tool, which changes what it does depending on where on a clip you point. The pointer shows what a drag will do.

Getting audio in

  • Drag files from Explorer or Finder, or from the Browser's Files tab, onto the timeline. A shaded preview shows where the clip will land before you let go, snapped to the grid.
  • Drag several files at once and Aerion asks how to place them: on separate tracks at the same position, one after another on one track, or stacked in lanes on one track.
  • File › Import Audio File… adds a file through a file chooser.

The Select tool on a clip

Point atDrag to
The middle of a clipMove it, along the song and onto another track.
The left or right edgeTrim it: make it start later or end earlier. Drag back out to restore what you trimmed.
The small dot in a top cornerSet a fade-in (left dot) or fade-out (right dot) on an audio clip.

Click a clip to select it. Clicking empty space deselects it.

Keyboard editing

ShortcutWhat it does to the selected clip
← / →Nudge it left or right.
Alt ← / Alt →Trim it shorter or longer.
DeleteDelete it.
XForce a crossfade where it overlaps another clip.

The same commands are in the Event menu. Ctrl Z undoes and Ctrl Shift Z redoes almost any edit.

Splitting with the Razor tool

Choose the Razor tool in the toolbar and click a clip where you want to cut it. With snap on, the cut lands on the grid.

Crossfades

When Auto-crossfade is on (toolbar, or Audio › Auto Crossfade), moving one audio clip over another fades smoothly between them across the overlap. Audio › Auto Crossfade Length sets the longest crossfade it creates: 10, 25, 50, 80, 120, 200 or 500 ms. Aerion never overwrites a fade you set by hand.

Comping takes

When you record several takes over the same part, they stack up on the track. Choose the Comp tool and click the take you want to hear; the takes overlapping it are muted. Split takes with the Razor tool first to pick the best take for each phrase.

Snap to grid

Snap makes moves, trims, cuts, the playhead, loop range and markers land on grid lines. Turn it on or off with the toolbar's magnet or Song › Snap to Grid, and pick the grid by right-clicking the magnet or from Song › Snap Interval.

Chapter 09

Tempo & time signature

Under the bar numbers, the ruler has two lanes: SIG for time signatures and TEMPO for tempo changes. The grid, the metronome and MIDI clips follow both.

Tempo changes

  • Double-click the tempo lane to add a tempo point there.
  • Drag a point up or down to change its tempo, or sideways to move it.
  • Right-click a point to delete it.

Time signature changes

  • Right-click an empty spot in the SIG lane to add a time signature at the start of that bar.
  • Drag a time signature to another bar.
  • Right-click a time signature to delete it. The first one, at bar 1, always stays.

For a single tempo or time signature for the whole song, type it into the transport bar instead.

Chapter 10

Recording

Recording takes three things: an armed track, an input, and the Record button.

  1. Select the track and look at the Inspector. Click the In setting to choose its input: a specific audio input, All audio inputs, a specific MIDI controller, or All MIDI controllers. MIDI inputs must first be enabled in Audio Settings.
  2. Arm the track with its R button or R.
  3. Set the monitoring (below), the metronome and the count-in if you want them.
  4. Press Ctrl R or the ● button. The waveform draws on the track as you record.
  5. Press Space or ■ to stop. The new clip is on the track.

Monitoring

Monitoring decides whether you hear the input through Aerion while you play. The Inspector's MON button cycles three modes:

ModeYou hear the input
AUTOWhen the track is armed. The usual choice.
ONAlways, armed or not.
OFFNever. Use this if your interface already sends the input to your headphones.

Metronome and count-in

  • Turn the click on with the toolbar's metronome button or Song › Metronome.
  • Right-click the metronome button for CLICK LEVEL (in dB) and Accent downbeat, which makes the first beat of each bar stand out.
  • The count-in plays 1 or 2 bars of click before recording starts. Set it with the toolbar's count-in button, or under Song › Count-In or Transport › Count-In.

Punch in and out

To re-record only part of a take, set a loop range around that part (Alt-drag on the ruler) and turn on Punch in/out in the toolbar or the Transport menu. Start playback before the range: Aerion records only between the loop's start and end.

Plugin delay compensation

Some plugins delay the sound they process. With PDC on (the default), Aerion delays the other tracks to match, so everything stays in time. Turn it off only if you need the lowest possible delay while recording through plugins.

Chapter 12

Instruments & plugins

Each track runs its sound through a chain of devices: instrument and effect plugins. Aerion hosts VST3 plugins on Windows and macOS, and Audio Units on macOS.

Finding your plugins

The Browser's Plugins tab lists every plugin Aerion found, grouped by maker. Plugins installed after Aerion started appear after you click RESCAN or choose Audio › Rescan Plugins. To hide a plugin you don't use, right-click it and choose Delete from Plugin Browser; it comes back on the next rescan if it is still installed.

Adding a device to a track

  • Drag a plugin from the Browser onto a track's header or a Mixer strip.
  • Click a Mixer strip's FX button, the Inspector's + next to INSERTS, or Add Plugin… in a track's right-click menu, and pick from the list.

The plugin's window opens straight away. On a MIDI track, put the instrument first in the chain, so the effects after it process its sound.

The device chain

The Inspector's INSERTS section, the Mixer's insert column and the track's FX window all list the same devices, top to bottom in the order the sound passes through them.

  • Click a device's name to open its window.
  • BYP bypasses it (the sound passes through unchanged); click again to turn it back on.
  • Drag the dotted handle to change its place in the chain.
  • Right-click for Open Editor, Bypass, Move Up, Move Down and Remove Plugin.

A plugin's settings, including any preset you chose in its own window, are saved with your project.

When a plugin crashes

✓

Windows: Aerion catches a plugin that crashes while it processes audio, loads, saves or restores its settings, or opens its window. The rest of your session keeps going, and a message names the plugin and what it was doing.

  • A plugin that crashed while processing audio is bypassed. Turn it back on with BYP to try again.
  • A plugin that crashed at any other point is switched off until you restart Aerion. Saving keeps the settings it had when you last saved.

On macOS, and inside a plugin window that is already open, a crashing plugin still closes Aerion. Your auto-saved session is offered on the next start.

Chapter 13

Mixing

The Mixer, in the bottom panel's Mixer tab, shows one strip per track and the master strip on the right.

Anatomy of a mixer strip

Colour band and name
The track's colour and name. Folder tracks show a folder icon; submix folders have a coloured outline.
Pan knob
Drag up to pan right, down to pan left. Double-click to centre it. The track's level in dB is shown next to it.
Insert column
The track's devices as small slots: dot to bypass, handle to reorder, right-click for the device menu.
Fader and meter
Click or drag on the fader to set the level. Double-click to reset it to 0 dB. The meter shows the level as it plays.

Mute, solo, and mono, which folds the track to mono.

Adds a plugin to this track.

The number under the fader is the loudest peak so far. Click it or the i button to reset it.

The strip's right-click menu

  • Re-enable Automation: see Automation.
  • Convert to Submix / Convert to Folder on folder tracks.
  • K-14 Reference Scale on the master: switches the master meter to the K-14 scale, where 0 on the meter sits 14 dB below full scale. Useful for keeping headroom while mixing.
  • Snapshots: see below.
  • Reset Peak.

The Inspector

The Inspector shows the selected track in more detail:

In / Out
The track's input (for recording) and its output, the main mix.
M S R
Mute, solo and record arm.
Phase (*)
Flips the track's polarity. Use it when two microphones on one source cancel each other out.
Mono (M)
Folds the track to mono.

Freezes or unfreezes the track.

Sends and buses

A send copies part of a track's sound to a bus, so several tracks can share one effect such as a reverb. Choose Add Send to New Bus… in the track's right-click menu. The send appears in the Inspector's SENDS section, where you set how much is sent.

Submix folders

Right-click a folder track and choose Convert to Submix. The folder gets its own fader, pan and meter, and all its tracks play through it, so you can, for example, set the level of a whole drum kit with one fader.

Mix snapshots

A snapshot remembers every fader, pan, mute and solo. Use one to compare two versions of a mix.

  1. Right-click a mixer strip and choose Snapshots › Save New Snapshot….
  2. Change the mix.
  3. To go back, choose the snapshot's name from the same menu.

Snapshots are saved with the project.

Chapter 14

Automation

Automation changes a track's volume or pan over time, by itself, as the song plays.

  1. Click the track's A button to show its automation lane under the track.
  2. Choose VOL or PAN in the lane.
  3. Click in the lane to add a point.
  4. Drag points to change their value or position. Right-click a point to delete it.

The fader and pan knob follow the curve during playback.

Overriding automation by hand

If you move the fader or pan knob of an automated track, your move wins: the track stops following its curve, and a yellow A appears on its fader in the Mixer. The curve itself stays in the project. To follow it again, right-click the mixer strip and choose Re-enable Automation.

i

Automation currently covers track volume and pan. Automating plugin settings, and recording automation by moving controls during playback, are planned.

Chapter 15

Freezing tracks

Freezing renders a track and its devices to audio, so its plugins stop using processor time. Use it when a heavy instrument or effect chain pushes the CPU meter towards red.

  • Choose Freeze Track in the track's right-click menu, or click FREEZE in the Inspector. While it renders, the button shows ….
  • A frozen track plays its rendered audio. Its clips and devices can't be changed until you unfreeze it.
  • Choose Unfreeze Track, or click UNFRZ, to edit it again.

Chapter 17

Customising Aerion

Workspace layouts

View › Workspace switches the whole window in one step. A layout remembers which side panels are open, whether the Mixer is docked, which bottom tab is showing, and how tall the bottom panel is.

LayoutSet up for
EditingArranging: all panels open, a compact Mixer under the timeline.
MixingMixing: Browser hidden, a tall Mixer.
RecordingTracking: Inspector open for inputs and monitoring, Browser hidden, a small Mixer.

Arrange the window the way you like it and choose View › Workspace › Save Current Layout… to keep it. Remove your own layouts with Delete Layout. Aerion reopens the last layout you used.

Interface size

View › UI Size scales the whole interface from 100 % to 200 %, which helps on large or high-resolution screens. Auto picks a size from your screen: 125 % on a 1440p display and 150 % on 4K.

On older or slower computers

  • View › Graphics Engine: Hardware Accelerated draws with the graphics card; Software draws with the processor, which is often faster for Aerion's many small updates. Auto chooses for you.
  • View › Lightweight UI uses flat colours and slower animations to save work. Auto turns it on for weaker machines.

Keyboard shortcuts

Help › Keyboard Shortcuts… lists every command and its key.

  1. Click a command, then press the new key or combination. Esc cancels.
  2. If the key is already used, Aerion asks whether to Reassign it.

Export… and Import… save and load your shortcuts as an .aerionkeys file, to take them to another computer. Reset to Defaults restores the original keys. Mouse gestures are shown for reference but can't be changed.

Chapter 19

Troubleshooting

No sound, or the wrong device

  • Check File › Audio Settings…: the right output, and the sample rate your interface uses.
  • Click Reset Audio Settings to return to a safe default.
  • On a MIDI track, check that it has an instrument plugin and that its input is your keyboard. New MIDI tracks start without one.

Clicks, pops or dropouts

  • Raise the buffer size in Audio Settings.
  • Watch the CPU meter in the transport bar. Freeze heavy tracks to bring it down.
  • On Windows, use your interface's ASIO driver if it has one.

A plugin is missing

  • Click RESCAN in the Browser's Plugins tab.
  • Check it's a format Aerion hosts: VST3, or Audio Unit on macOS. VST2 and CLAP plugins aren't supported.
  • A plugin that crashed during the scan is skipped. The Console tab lists it.

The Console

The Console tab in the bottom panel shows Aerion's log as it happens: device changes, plugin scans, warnings and errors. It is the first place to look when something doesn't work.

Crash reports

If Aerion crashes, it writes a report folder: what went wrong, where, the session's log and, on Windows, a memory dump. The next start tells you and offers to show it.

SystemCrash reports are kept in
Windows%APPDATA%\AerionDAW\Crashes
macOS~/Library/AerionDAW/Crashes

Reporting a problem

Please open an issue on GitHub. Say what you did, what you expected and what happened instead, and include your system, your audio interface and any plugins involved. After a crash, attach the report folder.

Chapter 21

Known limitations

What version 0.5.0 doesn't do yet.

  • No built-in instruments or effects. Aerion uses your VST3 and Audio Unit plugins; to play MIDI you need an instrument plugin.
  • Automation covers track volume and pan only, drawn by hand.
  • Plugin crash protection is Windows-only, and doesn't yet cover a crash inside a plugin window that is already open.
  • Not yet supported: time-stretching, sidechain routing, MIDI learn, control surfaces, project templates and loudness metering. All are planned.
  • No CLAP or VST2 plugins, and no Linux version.
  • Accessibility doesn't reach clips on the Timeline or notes in the Piano Roll yet.
  • AI tools and the Cloud tab in the Inspector and Browser are placeholders and don't do anything yet.
  • Unsigned installers: Windows and macOS warn on first install (see Installing).
